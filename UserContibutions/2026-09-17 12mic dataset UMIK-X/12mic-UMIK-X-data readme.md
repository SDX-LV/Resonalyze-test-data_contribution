Date: 		2026-09-17 
Captured with: 	Resonalyze 0.8.0 
Method:		12 mic array using miniDSP UMIK-X (center @ ch2)

Captured on completely untuned system using miniDSP UMIK-X array with 3x4mic modules which were custom-mounted so that one module with 4 mics was on the center axis and channel 2 is considered the main reference. All of this was using Asio4All to unify UMIK-X with an RME audio interface. UMIK-X is the clock master while RME provides loopback signal using the Toslink output from UMIK-X and then RME forwards the same Toslink clock and signal to the “DSP“ which produces sound on each speaker.

This dataset is taken from unusual setup with a mix of re-used speakers and amplifiers. Makes a great torture test to get this to a reasonable tune - not a high-end install with exquisite speakers. Think of this as OEM-style install in a classic car - working with limitations of unusual, small speaker positions.


Tweeters in this setup should not be played below 2500-3000 Hz
Midranges in this setup are likely to be crossed around 200 Hz
